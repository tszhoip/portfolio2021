Archive grid images.

Drop files here named 1.jpg, 2.jpg, 3.jpg ... in the order you want them
shown. .jpeg, .png and .webp also work.

The page probes numerically from 1 and stops once it hits a run of empty
slots, so keep the numbering contiguous. Up to 120 images.

No API, no token, nothing to configure - add files, commit, push.
